# Bayesian Latent Class Model for Treatment Heterogeneity

This repository contains the implementation of a Bayesian latent class model designed to identify heterogeneity of treatment effect (HTE) in critical care patients. 
The model uses a mixed-mode latent class approach to jointly model treatments and outcomes, leveraging Bayesian inference for robust estimation.

## Project Overview
Clinical trials often aim to identify how different patient subgroups respond to treatments, but traditional methods may not adequately account for treatment heterogeneity. Our Bayesian latent class model:
- Detects unobserved subgroups (latent classes) of patients with similar responses.
- Jointly models treatment allocation and outcomes, providing insights into causal pathways.
- Incorporates covariates and other key factors to improve subgroup detection.

This approach is particularly suited for adaptive trial designs and precision medicine applications.

---

## Features
- Bayesian latent class modeling framework.
- Flexible priors and hyperparameter settings.
- Integration of covariates and outcomes into a single probabilistic model.
- Simulation-based validation using Markov Chain Monte Carlo (MCMC) methods.
- Real-world application tested on critical care trial data (e.g., the PRACTICAL Platform trial).
